# Zenith Edges

Version 0.15.1

Hairline status edges, so nothing sits on screen while you read.

- **Top:** a sweep while the page loads (Zenith Plus shows real progress instead).
- **Bottom:** a sweep while a download runs (real progress with Zenith Plus).
- **Left:** the tab's container colour.
- **Frame:** private windows, and red while any tab uses your camera, mic or screen.
- **Top, amber:** pages without HTTPS.

Presets: **Quiet** keeps only loading, sharing and private. **Full** shows everything.
