# Zenith Tabs

Version 0.12.10

A tight tab sidebar that only shows the signals that matter: sleeping tabs, attention dots, folder activity, container stripes, audio waves and vertical split groups.

Presets: **Plain** (density and sleeping tabs only), **Informative**, or **Everything**, which also turns on every Extra.

**Numbered tabs** puts 1 to 9 on the tabs Ctrl+1 to Ctrl+9 jump to: Off, Always, or While holding Ctrl. The last one needs Zenith Plus; without it the numbers stay hidden.
