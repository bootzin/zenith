# Zenith Panels

Version 0.6.3

Find bar, Library card (Ctrl+H), link URL pill, Glance, split view, notifications and menus, all on the same glass and corners.

- **Find bar:** a single floating line. Its options show while you hover it.
- **Split view:** i3-style tiling gaps (2px to 24px) with an accent border on the active pane.
- **Compact menus:** off unless you choose them.
