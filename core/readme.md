# Zenith Core

Version 0.12.11

Shared colours, sizes, transparency and motion timing for every Zenith mod, plus the page frame. The other Zenith mods need it.

- **Density** sets the row height of sidebar tabs and of the URL bar's Dense results: Tight, Compact (4px taller) or Cozy (8px taller).
- **Screen scale** picks sizes from the window width: small (up to 1400px, for 1280x720 and 1366x768), medium, or large (2200px and up, for 2560x1440).
- **Accent colour** follows the workspace, or picks one from a fixed palette: lavender, blue, teal, green, amber, orange, red, pink or grey.
- **Window transparency** is one setting for everything: the window, the sidebar, the URL bar popup, the Library and the glass panels. Solid, Dense, Balanced (Zen's own look), Airy (the default), Sheer or Glass. The sidebar follows it like the URL bar. Web pages stay opaque.
- **Frost** sets how much see-through surfaces blur what's behind them. It shows most from Airy up.
- **Sidebar**: see-through like the URL bar (default), solid so docked and floating are always identical, or Zen's own darker floating sidebar. With Zenith Plus, docked and floating use exactly the same workspace colour; without it, the floating one uses Zen's slightly darker sidebar colour.
- **Page frame**: flush and square, rounded with a slim gap, or Zen's default.
